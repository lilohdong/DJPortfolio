"당신의 상식은 상위 몇 %일까?"를 내건 퀴즈 웹사이트입니다. 객관식, 주관식, O/X, 넌센스 퀴즈를 풀고 상대평가 티어로 자기 수준을 확인합니다. 회원가입 없이 닉네임만 입력하면 참여할 수 있고, PC와 모바일을 모두 지원합니다. 2학년 1학기 UX/UI 프로그래밍 과목의 개인 프로젝트로 기획부터 디자인, 개발까지 혼자 진행했습니다.

유형마다 문제 테이블에서 무작위로 25문제를 뽑아 시작할 때마다 다른 문제가 나옵니다. 결과 화면에서는 점수와 상위 퍼센트, 해당 유형의 TOP 10을 보여 주고, 상위 퍼센트를 브론즈부터 챌린저까지의 티어로 바꿔 표시합니다. 첫 화면에서는 유형별 실시간 랭킹을 볼 수 있습니다.

넌센스 퀴즈에는 객관식, 주관식, O/X를 모두 넣고 문제 유형에 따라 다르게 표시했으며, DB에서는 유형별 뷰를 사용했습니다. 주관식은 문제 테이블과 정답 테이블을 분리해 정답을 여러 개 등록할 수 있게 하고, 비교할 때 공백을 지우고 소문자로 바꿉니다.

모든 출력에 이스케이프를 적용하고 DB 조회는 Prepared Statement로 처리했습니다. 시맨틱 태그, 미디어 쿼리, label과 input 연결, 이미지 대체 글로 웹 표준과 접근성을 챙겼습니다.
