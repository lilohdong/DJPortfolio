POS PLACE는 PC방 카운터에서 쓰는 POS 프로그램입니다. 좌석 상태, 상품 주문, 재고, 회원, 직원, 매출, 교대 인수인계를 한 프로그램에서 관리하는 Java Swing과 MySQL 기반 데스크톱 앱으로, 2학년 2학기 객체지향언어실습 기말 팀 프로젝트로 만들었습니다.

저는 팀에서 커밋이 가장 많은 기여자로, 초기 실행 구조와 메인 프레임·사이드바 네비게이션, Gradle 전환 등 프로젝트 구조를 잡았습니다. 관리자 로그인은 로그인 확인을 유틸로 분리하고 사용자 정의 예외로 다시 구성했습니다. 매출과 직원 관리는 관리자 모드에서만 접근할 수 있습니다.

DB는 전체 구조를 설계하고 초기화 SQL과 더미 데이터, 매출용 뷰를 작성했습니다. DB 연결을 싱글톤으로 두었다가 연결이 계속 닫히는 문제가 생겨, 매번 생성하고 해제하는 방식으로 바꿨습니다.

매출 관리는 음식 매출과 시간 상품 매출을 나누어 일·주·월 단위로 조회할 수 있게 했고, 게임 통계에서는 게임별 이용 통계와 인기 게임 순위를 보여 줍니다. 화면마다 배경색을 직접 지정하던 코드를 걷어내고 다크/라이트 모드 전환으로 일괄 관리하도록 UI 전체를 개편했습니다.

프로그램 전체로는 정전에 대비한 좌석 상태 주기적 저장, 재고 부족 메뉴 주문 차단, 레시피 기반 재료 자동 차감, 취소·환불 시 매출 자동 차감, 교대 시 매출 자동 집계와 금고 차액 계산 기능이 있습니다.
